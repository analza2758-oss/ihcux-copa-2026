# ⚽ CopaNaMão — Protótipo de Baixa Fidelidade (IHC & UX)

## 📚 Sobre o Projeto

Este projeto foi desenvolvido para a disciplina de Interação Humano Computador e UX, do Centro Universitário UNA, com orientação do professor Daniel Henrique Matos de Paiva.

A proposta da atividade consiste na criação de um protótipo de baixa fidelidade do aplicativo **CopaNaMão**, utilizando o Miro, com foco em melhorar a experiência dos torcedores dentro de uma arena da Copa do Mundo.

O aplicativo foi pensado para auxiliar usuários em ambientes lotados e barulhentos, priorizando:

* Facilidade de navegação
* Rapidez nas ações
* Leitura clara
* Usabilidade sob pressão

## 🎯 Problema Focado

O principal problema priorizado pelo grupo foi:

### 🍔 Filas enormes nos quiosques de comida

Muitos torcedores perdem momentos importantes da partida enquanto aguardam atendimento em filas de alimentação.

### 💡 Solução proposta

O aplicativo oferece:

* Pedido digital de comidas e bebidas
* Retirada rápida via notificação
* Possibilidade de entrega no assento
* Acompanhamento do status do pedido em tempo real

Além disso, o projeto também auxilia na:

* Localização dentro do estádio
* Acesso rápido aos replays dos lances

---

## 🧠 Justificativa de Design

O design do protótipo foi pensado para situações reais de uso dentro de um estádio, considerando:

* Distrações constantes
* Iluminação variável
* Ambiente barulhento
* Necessidade de rapidez

### 🎨 Principais decisões de UX

* **Botões grandes:** facilitam o toque rápido durante o jogo
* **Informações prioritárias no topo:** placar, replay e pedidos aparecem primeiro
* **Navegação simplificada:** poucas etapas para completar ações importantes
* **Ícones intuitivos:** ajudam na identificação rápida das funções
* **Fluxo direto:** reduz o tempo fora da experiência da partida

---

## 🔄 Fluxo do Usuário

### 🍟 Fluxo para pedir um lanche

1. Usuário acessa a tela inicial
2. Seleciona o botão **Cardápio**
3. Escolhe os produtos desejados
4. Adiciona itens ao carrinho
5. Finaliza o pagamento
6. Recebe notificação quando o pedido estiver pronto
7. Retira o pedido ou aguarda entrega no assento

---

### 🎥 Fluxo para assistir replay

1. Usuário acessa a Home
2. Seleciona **Central de Replays**
3. Escolhe o lance desejado
4. Assiste ao replay em múltiplos ângulos
